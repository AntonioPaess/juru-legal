# Juru — Legal & Support

Juru is a facial gesture-driven communication app for iPad, designed for people with motor impairments. Distinguished Winner of the Apple Swift Student Challenge 2026.

This repository hosts the public privacy policy and support page for the app.

## Pages

- [Privacy Policy](./privacy-policy.html)
- [Support](./support.html)

## About Juru

Juru turns subtle facial gestures — a brow raise, a lip pucker — into typed words and spoken speech. It runs entirely on-device, with no internet connection, no accounts, and no data collection.
